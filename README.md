# Автошкола — курсовой проект

Мобильная корпоративная информационная система для администратора автошколы. Android-приложение написано на **Kotlin и Jetpack Compose**, сервер — на **Kotlin/JVM**. Серверная БД PostgreSQL и отдельная локальная БД SQLite содержат шесть связанных предметных таблиц.

- Создание и редактирование учеников, групп и практических занятий; поиск по всем реестрам.
- Просмотр категорий, инструкторов и автопарка; сводка по группам и расписанию.
- Хранимые процедуры, триггеры, проверка вместимости и пересечений, защита от перезаписи чужих изменений.
- Без сети доступны просмотр и поиск в последней локальной копии. При первом открытии доступен встроенный демонабор: 12 учеников, 10 занятий, 4 группы, 4 инструктора, 5 автомобилей и 3 категории. Запись возможна только после подключения.

## Сборка Android

Откройте корневую папку в Android Studio, установите Android SDK 37 и Build Tools 36.0.0. Для Gradle используйте встроенную JBR 25 или JDK 17–25. Приложение рассчитано на Android 8.0 (API 26) и новее.

```powershell
.\gradlew.bat :app:assembleDebug
```

После сборки APK будет в `app/build/outputs/apk/debug/app-debug.apk`. В Android Studio дождитесь импорта Gradle, затем выберите конфигурацию **Автошкола** (или `app`), устройство и нажмите **Run**. Если модуля `app` нет, откройте корневой `build.gradle.kts` через **File → Open → Open as Project**. Для просмотра демоданных запускать сервер необязательно.

На macOS/Linux используйте `sh ./gradlew` вместо `.\gradlew.bat`.

## Запуск с записью данных

1. Из корня запустите PostgreSQL. Если Docker не установлен, можно вручную создать пустую БД `avtoschool` в PostgreSQL 16 и указать реквизиты переменными окружения.
2. Запустите сервер с `--init-demo`. Этот аргумент создаёт схему и добавляет демоданные только в ранее не инициализированную базу; при последующих запусках данные не сбрасываются.
3. В Android-эмуляторе откройте **Подключение**, оставьте адрес `http://10.0.2.2:8080` и ключ `school-demo`, нажмите **Подключиться**. Откройте «Ученики», «Группы» или «Вождение» и нажмите «Добавить». Для изменения нажмите нужную карточку. Для ручной синхронизации нажмите «Обновить».

```powershell
docker compose -f server/compose.yaml up -d --wait
.\gradlew.bat :server:run --args="--init-demo"
```

Проверка сервера с компьютера: `curl.exe http://127.0.0.1:8080/health`. Доступ на физическом телефоне возможен в своей локальной сети: перед запуском задайте `SCHOOL_HOST=0.0.0.0`, собственный `SCHOOL_TOKEN` и введите в приложении IP компьютера и тот же ключ. По умолчанию API слушает только `127.0.0.1:8080`. При необходимости задайте `SCHOOL_PORT`, `SCHOOL_DB_URL`, `SCHOOL_DB_USER` и `SCHOOL_DB_PASSWORD`. Значения по умолчанию: `jdbc:postgresql://127.0.0.1:5432/avtoschool`, `avtoschool`, `avtoschool_demo`. Учётная запись при установке схемы должна иметь право создать расширение `btree_gist`.

Это учебная конфигурация: образцы вымышлены, общий ключ не заменяет персональные учётные записи, HTTP не предназначен для реальных персональных данных. Для физического устройства и HTTP используйте только доверенную учебную сеть. Для эксплуатации нужны HTTPS, индивидуальная авторизация, аудит и резервное копирование.

## Проверки

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
py tests/api_smoke.py
```

`tests/api_smoke.py` запускается против поднятого API с **отдельной тестовой БД** и оставляет успешные тестовые записи. При другом адресе и ключе передайте `--url` и `--token`. Тестирует создание и изменение, ошибки формата, вместимость, внешние ключи, конфликт версий, пересечение времени и конкурентную запись.

Чтобы отрисовать Compose-предпросмотры, выполните `.\gradlew.bat :app:updateDebugScreenshotTest`. Эталонные PNG генерируются локально и не хранятся в репозитории.

## Структура проекта

- [`app`](app/) — интерфейс Android и локальная база SQLite.
- [`server`](server/) — HTTP API и доступ к PostgreSQL через JDBC.
- [`shared`](shared/) — общие модели клиента и сервера.
- [`database/schema.sql`](database/schema.sql) — схема, процедуры и триггеры; [`database/seed.sql`](database/seed.sql) — демонстрационные данные.
